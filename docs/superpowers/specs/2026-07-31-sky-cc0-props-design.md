# 天空道具升级 · CC0 云 + 柔光日月

日期: 2026-07-31  
分支: `feature/cocos-rewrite`  
状态: 已确认（路线 A）  
关联: `docs/superpowers/specs/2026-07-29-bamboo-cocos-rewrite-design.md` Task 12 天空表现增强

## 背景

当前 `SkyView` 为程序化渐变 + 点状星星 + 简单球体日月，观感偏简陋。需要在不改玩法的前提下，用 **CC0** 资源与柔光表现提升天空氛围。

## 已确认偏好

| 项 | 选择 |
|---|---|
| 美术风格 | 柔和插画风 |
| 云密度 | 分层氛围（近 + 远） |
| 包体预算 | 观感优先，天空相关合计 ≤ ~2MB |
| 实现路线 | **A**：CC0 云 GLB + 柔光日月（混合） |

## 目标

1. 保留程序化渐变天空与星星（省天空盒体积）。
2. 日月改为柔光球体 + 半透明光晕；随高度系数 `k` 昼夜切换，短淡入淡出。
3. 云使用 Quaternius CC0 Cloud GLB；近/远两层慢漂；中带避让，减少挡竹/熊猫/金币。
4. 模型缺失时降级可玩（无云、日月退回无光晕球体）。
5. 资源登记 `ASSETS.md`；`models` 分包与后续小熊猫共用。

## 非目标

- 不做全景天空盒 / HDRI。
- 不把云做成玩法碰撞体。
- 本次不强制接入独立太阳/月亮 GLB（以程序化柔光为主；可选 CC0 贴图）。
- 不在本任务完成小熊猫/植被（仍属 Task 16）。

## 架构

```
Camera3D
├── SkyQuad          程序化渐变（已有）
├── Stars[]          闪烁（已有）
├── SunMoon          主体球 + Halo 盘；k 驱动外观
└── CloudRoot
    ├── FarClouds[]  更淡、更后、慢漂
    └── NearClouds[] 两侧/边缘，避开中带
```

- 逻辑仍集中在 `view/SkyView.ts`；Bootstrap 仅在需要时传入/触发 bundle 加载（可与现有 `build(camNode)` 扩展）。
- 加载：`assetManager.loadBundle('models')` → `sky/cloud`（路径以导入后资源名为准）。
- 高度系数沿用：`k = clamp01(heightPx / (PX_PER_M * 200))`。

## 表现规则

### 日月

- 位置：相机局部右上（与现坐标同量级），略前于天空平面。
- 太阳：暖黄主体 + 更大半透明光晕；月亮：冷白主体 + 较弱光晕（可贴可选 CC0 漫反射，≤512）。
- `k < 0.5` 太阳，否则月亮；切换约 0.3s 透明度交叉，避免硬切。

### 云

- **远景层**：实例较少、更小、更透明、更靠后，左右缓慢循环漂移。
- **近景层**：稍大，主要分布画面左右与上下边缘。
- **避让带**：相对相机视野中心水平约 ±17.5%（总宽约 35%，以竹子中轴为心）不放置近景云。
- **高度淡出**：低空明显 → 随 `k` 变淡偏冷 → 高 `k` 接近消失，突出星月。

### 降级

| 失败点 | 行为 |
|---|---|
| `models` bundle / `cloud.glb` 缺失 | 跳过云，打日志，游戏继续 |
| 贴图缺失 | 日月仅用纯色柔光材质 |
