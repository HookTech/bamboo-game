# 节节高 · 解压小游戏原型

小熊猫抱着竹子,有节奏地按 `空格`,竹子节节往上长,一路采集天上飘的金币。

## 运行

```bash
cd bamboo-game
python3 -m http.server 8931
# 浏览器打开 http://localhost:8931
```

直接双击 `index.html` 也能玩(无依赖,纯 Canvas + WebAudio)。

## 玩法

| 操作 | 效果 |
|---|---|
| 空格(间隔 0.12s–0.55s) | 竹子生长,连击 +1(上限 x12),连击越高单次长得越多 |
| 按太急(<0.12s) | 竹子眩晕 0.9s,连击清零,屏幕抖动 |
| 按太慢(>0.55s) | 连击中断重新计 |

- 金币靠近小人会磁吸,拾取得分 `1 + 连击/4` 倍率
- 高度越高天色由白昼渐入星空,最高纪录存 localStorage
- 无失败惩罚,纯解压

## 文件

- `index.html` — 入口 + 开始遮罩
- `style.css` — 页面样式
- `game.js` — 全部游戏逻辑(状态机/节奏判定/生成/渲染/音效)
